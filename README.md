# Keep 🐜 — Бот для муравьёв

Telegram-бот «Keep» на Python (библиотека **aiogram 3.x**) для сохранения заметок.
Идеально подходит муравьеводам: записывайте кормёжки, планы по колониям и товары — всё хранится в SQLite.

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие |
| `/help` | Список команд |
| `/keep <текст>` | Сохранить заметку |
| `/list` | Показать все заметки |
| `/delete <номер>` | Удалить заметку по номеру из `/list` |

## Структура проекта

```
Keep/
├── bot.py            # Главный файл: запуск бота, логирование, long polling
├── config.py         # Настройки: токен, путь к БД, лимиты
├── database.py       # Работа с SQLite (таблица notes: id, user_id, text, created_at)
├── handlers.py       # Обработчики команд бота
├── requirements.txt  # Зависимости
└── README.md         # Эта инструкция
```

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/MyKuper/Keep.git
   cd Keep
   ```

2. **Создайте виртуальное окружение и установите зависимости:**
   ```bash
   python -m venv venv
   source venv/bin/activate        # Linux/macOS
   # venv\Scripts\activate         # Windows
   pip install -r requirements.txt
   ```

3. **Получите токен у [@BotFather](https://t.me/BotFather):**
   - найдите бота @BotFather в Telegram;
   - отправьте команду `/newbot`, придумайте имя (например, `Keep`) и username
     (например, `MyKuperKeepBot` — должен заканчиваться на `bot`);
   - BotFather пришлёт токен вида `123456789:AAH...` — скопируйте его.

4. **Укажите токен** удобным способом:
   - самый простой — помощник `setup_token.py` (проверит токен через API
     и сохранит его в `.env`, который не попадает в git):
     ```bash
     python setup_token.py 123456789:AAH_ваш_токен
     ```
   - или вручную создайте файл `.env` со строкой `BOT_TOKEN=123456:ABC-...`;
   - или задайте переменную окружения:
     ```bash
     export BOT_TOKEN="123456:ABC-your-token"
     ```
   - или впишите токен прямо в `config.py` (переменная `BOT_TOKEN`).

5. **Запустите бота:**
   ```bash
   python bot.py
   ```

База данных SQLite (`keep.db`) создаётся автоматически при первом запуске.

## Хранение данных

Заметки сохраняются в таблице `notes` базы данных SQLite:

| Поле | Тип | Описание |
|---|---|---|
| `id` | INTEGER | Уникальный номер заметки (AUTOINCREMENT) |
| `user_id` | INTEGER | Telegram ID пользователя |
| `text` | TEXT | Текст заметки |
| `created_at` | TEXT | Дата и время создания |

## Обработка ошибок и логирование

- Все обработчики команд обёрнуты в `try/except` — при ошибке пользователь получает понятное сообщение, а полная трассировка пишется в лог (`logging`, уровень `INFO`/`ERROR`).
- Ошибки работы с базой данных логируются в `database.py`.
- Логи выводятся в консоль с датой, временем и именем модуля.
